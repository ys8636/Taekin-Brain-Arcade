# v50 사용자 인터페이스 정리

## 변경 사항

1. 통합 설정 팝업에서 글씨 25~200%, 전체 화면 70~130% 조절 행을 삭제하고 메인 화면 바깥의 `글씨·화면` 빠른 조절 버튼만 유지했습니다. 저장 키 `taekin_arcade_preferences_v32`, 기존 JSON 백업과 배율 값은 변경하지 않았습니다.
2. 음악 목록을 설정창 내부의 상대 위치 드롭다운에서 별도 모달 다이얼로그로 변경했습니다. 6곡을 큰 터치 버튼으로 표시하고 선택 상태를 별도 줄로 표시하여 좁은 화면에서 잘리지 않도록 했습니다.
3. 음악창에서 곡 선택 후 즉시 닫기, 닫기 버튼, ESC, 팝업 바깥 누르기를 지원합니다. 선택한 음악은 기존 오디오 엔진과 로컬 저장 로직을 그대로 사용합니다.
4. CSS 가로 폭 280·320·390px 및 PC 1366px 화면에서 다이얼로그 열기, 곡 선택 및 닫기를 점검했습니다.

## 유지 사항

게임 6종, 1,500단계, BGM MP3 6곡, 저장·백업 호환성, 글씨·화면 빠른 조절 기능을 유지했습니다. 공개 GitHub Pages 적용은 새 파일을 해당 저장소에 커밋한 뒤 별도로 확인해야 합니다.
