## 🕹️ 어떤 게임이 있나요?

| 게임 | 목표 | PC / 스마트폰 조작 |
|:--|:--|:--|
| ⚾ **숫자야구** | 힌트의 스트라이크·볼을 이용해 비밀 숫자 추리 | 숫자 입력 후 확인 |
| 🔢 **2048** | 같은 숫자를 합쳐 목표 타일 만들기 | 방향키 / **화면 스와이프** |
| 💣 **지뢰찾기** | 지뢰를 피해 안전한 칸 모두 열기 | 클릭 / 터치·깃발 모드 |
| 🔧 **파이프 연결** | 시작점부터 도착점까지 물길 연결 | 클릭 / 파이프 터치로 회전 |
| 🧩 **시카쿠** | 숫자에 맞는 넓이의 직사각형으로 판 나누기 | 두 칸 선택 / 드래그 |
| 🟩 **블록 퍼즐** | 블록을 배치해 가로·세로 줄 지우기 | 선택·배치 / 드래그 |

## ✨ 이렇게 플레이해요

**① 게임 선택 → ② 난이도 선택 → ③ 단계 도전 → ④ 기록·업적 달성!**

- 게임마다 **5가지 난이도 × 50단계 = 250단계**, 총 **1,500단계**에 도전할 수 있어요.
- 처음 게임에 들어가면 **짧은 규칙 안내**를 선택할 수 있어요. 원하지 않으면 다시 묻지 않아요.
- 막히면 **도움말·힌트**를 사용하고, **도전 모드·배지·칭호**도 즐겨 보세요.
- 진행 상황은 **브라우저에 자동 저장**돼요. 다른 기기로 옮길 때는 JSON 백업·복원 기능을 이용하세요.

<details>
<summary><strong>📱 스마트폰 조작 팁 펼치기</strong></summary>

- **2048:** 게임판을 상하좌우로 쓸어 타일 이동
- **지뢰찾기:** 열기/깃발 모드를 바꾼 다음 칸 터치
- **시카쿠·블록 퍼즐:** 손가락으로 드래그하거나 칸 선택
- **글씨·화면 버튼:** 끌어서 위치를 옮길 수 있고, **3초간 누르면** 숨기기 확인창이 떠요. 숨긴 버튼은 **⚙ 설정**에서 복구할 수 있어요.
