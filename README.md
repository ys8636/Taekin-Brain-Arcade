## 🚀 처음 시작하는 방법

1. **[게임 사이트 열기](https://ys8636.github.io/Taekin-Brain-Arcade/play.html)**를 누릅니다.
2. 메인 화면에서 원하는 **게임 카드**를 선택합니다.
3. **난이도와 단계**를 확인하고 플레이합니다.
4. 첫 입장 시 **짧은 게임 설명을 볼지 선택**할 수 있어요. 필요 없다면 다시 묻지 않도록 설정할 수 있습니다.
5. 화면의 **도움말·힌트**를 활용하고, 클리어 후 다음 단계에 도전하세요.

## 🕹️ 게임 6종 소개와 플레이 방법

| 게임 | 목표 | PC 조작 | 스마트폰 조작 |
|:---|:---|:---|:---|
| ⚾ **숫자야구** | 비밀 숫자 추리 | 숫자 입력 | 숫자 입력 후 확인 |
| 🔢 **2048** | 같은 타일을 합쳐 목표 달성 | 방향키 / WASD | **게임판 상하좌우 스와이프** |
| 💣 **지뢰찾기** | 지뢰를 피해 안전한 칸 열기 | 클릭 / 오른쪽 클릭 | **열기·깃발 모드 전환 + 터치** |
| 🔧 **파이프 연결** | 누수 없이 물길 연결 | 파이프 클릭 | 파이프 터치해 회전 |
| 🧩 **시카쿠** | 숫자 넓이에 맞게 영역 분할 | 두 모서리 선택 / 드래그 | 두 칸 터치 / 드래그 |
| 🟩 **블록 퍼즐** | 가로·세로 줄 완성해 점수 획득 | 블록 선택 / 드래그 | 블록 선택 / 손가락 드래그 |

<details>
<summary><strong>⚾ 숫자야구 — 스트라이크와 볼로 비밀 번호 찾기</strong></summary>

- **목표:** 화면에 표시된 자릿수에 맞춰 중복 없는 숫자를 추리합니다. 단계와 난이도에 따라 자릿수와 시도 횟수가 달라집니다.
- **스트라이크(S):** 숫자와 위치가 모두 맞는 경우입니다.
- **볼(B):** 숫자는 정답에 있지만 위치가 다른 경우입니다.
- **아웃(OUT):** 입력한 숫자가 정답에 포함되지 않는 경우입니다.
- **플레이:** 숫자를 입력하고 **결과 확인**을 누릅니다. 이전 결과를 비교하며 가능한 숫자를 좁혀 보세요.
- **스마트폰:** 화면 숫자 입력칸을 터치해 키보드로 입력한 뒤 확인 버튼을 누르면 됩니다.

</details>

<details>
<summary><strong>🔢 2048 — 같은 숫자를 합쳐 더 큰 타일 만들기</strong></summary>

- **목표:** 같은 숫자 두 개를 합쳐 단계별 목표 타일과 점수를 달성합니다. 예를 들어 `2 + 2 → 4`, `4 + 4 → 8`입니다.
- **PC:** 키보드 **방향키 / W·A·S·D** 또는 화면 방향 버튼으로 타일을 움직입니다.
- **스마트폰:** 게임판을 **위·아래·왼쪽·오른쪽으로 쓸어 넘기면(스와이프)** 타일이 움직입니다. 화면 방향 버튼도 사용할 수 있습니다.
- **팁:** 빈 공간을 확보하고 큰 숫자를 한쪽에 모으는 전략이 도움이 됩니다. 필요하면 **되돌리기** 기능도 사용하세요.

</details>

<details>
<summary><strong>💣 지뢰찾기 — 숫자를 단서로 지뢰 피하기</strong></summary>

- **목표:** 지뢰를 건드리지 않고 지뢰가 없는 **안전한 칸을 모두 열면 성공**합니다.
- **숫자 의미:** `1`이 쓰인 칸은 주변 8칸 중에 지뢰가 한 개 있다는 뜻입니다.
- **PC:** 왼쪽 클릭으로 칸을 열고, 오른쪽 클릭으로 의심되는 칸에 깃발을 놓습니다.
- **스마트폰:** 화면의 **열기 / 깃발** 모드를 전환한 다음 원하는 칸을 터치합니다.
- **팁:** 처음 누른 칸과 그 주변은 안전하게 시작하도록 설계되어 있습니다.

</details>

<details>
<summary><strong>🔧 파이프 연결 — 시작점에서 도착점까지 물길 만들기</strong></summary>

- **목표:** 파이프를 회전시켜 **START에서 GOAL까지** 물이 흐르게 만들고, 모든 칸이 연결되도록 합니다.
- **PC:** 파이프를 클릭하면 회전합니다.
- **스마트폰:** 원하는 파이프를 손가락으로 터치하면 회전합니다.
- **팁:** 파이프끼리 열린 방향이 마주 봐야 연결됩니다. 물 흐름 애니메이션과 힌트를 확인해 보세요.

</details>

<details>
<summary><strong>🧩 시카쿠 — 숫자에 맞는 직사각형으로 칸 나누기</strong></summary>

- **목표:** 게임판 전체를 직사각형으로 나누되, **각 직사각형에 숫자가 정확히 하나**만 들어가도록 만듭니다.
- **핵심 규칙:** 직사각형의 넓이(칸 수)가 안에 적힌 숫자와 같아야 합니다. `6`이라면 `2×3` 또는 `1×6` 형태 등이 가능합니다.
- **PC:** 두 모서리 칸을 클릭하거나 드래그해서 영역을 선택합니다.
- **스마트폰:** 시작 칸과 끝 칸을 순서대로 터치하거나, 손가락으로 드래그해 선택합니다.
- **팁:** 영역끼리 겹치면 안 되며 빈칸도 남기지 않아야 합니다. 잘못 지정한 영역은 지우개 기능으로 지울 수 있어요.

</details>

<details>
<summary><strong>🟩 블록 퍼즐 — 줄을 채우고 목표 점수 달성하기</strong></summary>

- **목표:** **10×10 게임판**에 블록을 놓고 가로 또는 세로의 10칸을 채워 줄을 지웁니다.
- **진행:** 화면의 블록 세 개를 모두 사용하면 다음 세 개가 나옵니다. 더는 놓을 자리가 없으면 게임 오버입니다.
- **PC:** 블록을 고른 뒤 놓을 칸을 클릭하거나 마우스로 드래그합니다.
- **스마트폰:** 블록을 선택하고 빈칸을 터치하거나, 손가락으로 끌어서 배치합니다.
- **팁:** 초록색 배치 미리보기는 놓을 수 있는 자리이고, 빨간색은 놓을 수 없는 자리입니다. 블록은 회전할 수 없으니 빈 공간을 잘 관리하세요.

</details>

| 기능 | 설명 |
|---|---|
| 🎯 **난이도·단계** | 쉬움 / 보통 / 어려움 / 매우 어려움 / 전문가, 각 50단계씩 게임당 250단계 · 총 **1,500단계** |
| 🏁 **보스 단계** | 각 난이도의 10·20·30·40·50단계에 특별한 도전 구간 배치 |

| 💡 **힌트·되돌리기** | 막힐 때 게임별 힌트를 사용하고 일부 게임에서 되돌리기 지원 |
| 🏆 **도전과 보상** | 100라운드 종합 도전, 일일·주간 미션, 배지·칭호·트로피 등 |
| 🎵 **음악과 효과음** | 배경음악 6곡 선택과 게임 효과음·음량 설정 지원 |
| 💾 **자동 저장** | 단계 진행·기록·설정 등을 브라우저에 저장, JSON 백업·복원 지원 |

## 📱 스마트폰에서는 이렇게 사용하세요

- **드래그·스와이프:** 2048은 스와이프, 시카쿠와 블록 퍼즐은 손가락 드래그를 지원합니다.
- **게임판 크기:** 게임판 주변의 `−` / `＋` / `기본` / `화면 맞춤`으로 크기를 조절할 수 있습니다.
- **글씨·화면 버튼:** 오른쪽 아래 버튼을 짧게 누르면 조절창이 열리고, **끌면 위치를 이동**할 수 있습니다. **3초 이상 길게 누르면 숨기기 확인창**이 나타납니다. 숨겨도 **⚙ 설정에서 다시 표시**할 수 있어요.
- **게임 나가기:** 플레이 중 다른 화면으로 이동할 때 게임 전용 확인창이 나타날 수 있습니다.

## 💾 기록 저장과 백업

플레이 기록과 설정은 **현재 사용하는 브라우저**에 저장됩니다. 같은 기기와 브라우저에서 다시 접속하면 이어서 플레이할 수 있어요.

기기를 바꾸거나 저장 데이터를 보관하고 싶다면 **설정의 JSON 백업·복원**을 사용하세요. 브라우저 데이터를 삭제하면 기록이 사라질 수 있습니다.
