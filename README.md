# TAEKIN BRAIN ARCADE 🎮

**TAEKIN BRAIN ARCADE**는 여섯 가지 두뇌 게임을 한곳에서 즐길 수 있는 무료 웹 아케이드입니다. 별도의 프로그램 설치 없이 PC나 스마트폰 브라우저에서 바로 플레이할 수 있습니다.

> 게임은 브라우저에서 바로 실행되며 기록은 현재 기기의 브라우저에 저장됩니다.

**🎮 지금 플레이하기 (항상 최신 화면 요청):** https://ys8636.github.io/Taekin-Brain-Arcade/play.html

## 게임 종류

| 게임 | 목표 | 기본 조작 |
|---|---|---|
| 숫자야구 | 서로 다른 숫자의 자리와 값을 추리 | 숫자를 입력하고 스트라이크·볼 결과 확인 |
| 2048 | 같은 숫자 타일을 합쳐 목표 타일 만들기 | 키보드 방향키/WASD, 화면 방향 버튼 또는 게임판 스와이프 |
| 지뢰찾기 | 지뢰를 피하며 안전한 칸 모두 열기 | 칸 터치·클릭, 깃발 모드로 지뢰 표시 |
| 파이프 연결 | 시작점에서 끝점까지 파이프 연결 | 파이프를 누르거나 클릭해 회전 |
| 시카쿠 | 숫자를 포함한 정확한 넓이의 직사각형으로 판 나누기 | 두 칸 선택 또는 드래그 |
| 블록 퍼즐 | 블록을 배치해 줄을 없애고 목표 점수 달성 | 블록 선택 후 배치 또는 드래그(칸에 맞춰 미리보기) |

- 게임마다 **쉬움·보통·어려움·매우 어려움·전문가**의 5개 난이도와 난이도별 50단계가 있습니다. **게임 6종 × 250단계 = 총 1,500단계**로 구성되어 있습니다.
- **도전 모드**, 일일·주간 미션, 레벨·칭호, 배지·트로피, 꾸미기 요소를 제공합니다.
- 게임마다 **도움말·튜토리얼·TIP·힌트**를 제공해 처음 플레이하는 사람도 규칙을 배울 수 있습니다.
- 게임 진입 시 기본 **화면 맞춤**, 상시 표시되는 게임판 **확대·축소 버튼**, 다크/라이트 테마, BGM·효과음, 진행 기록 저장과 JSON 백업·복원을 지원합니다.

## 시작하기

1. 위 **지금 플레이하기** 링크를 PC 또는 스마트폰 브라우저에서 엽니다. 링크 주소는 버전이 바뀌어도 그대로입니다.
2. 메인 메뉴의 **게임**에서 원하는 게임을 선택합니다.
3. **난이도와 단계**를 선택한 후 게임을 시작합니다. 선택한 난이도는 1단계부터 차례로 클리어해 해금합니다.
4. 규칙이 낯설다면 **게임 도움말**을 눌러 게임 방법을 읽습니다.
5. 게임 제목 옆의 **📖 도움말**에서 게임 소개·조작 방법·단계 목표·힌트 안내를 확인합니다. 게임판 크기 조절 버튼은 게임 안에 항상 표시되며, 게임을 새로 열면 처음 실행할 때 기본적으로 **화면 맞춤**이 적용됩니다. 이전에 직접 지정해 저장한 게임별 배율은 유지됩니다. **− / ＋ / 기본 / 화면 맞춤**으로 직접 조정할 수 있습니다.
6. **내 기록**에서 진행 상황을 확인하고, 기기를 옮길 때는 **JSON 백업·복원**을 이용합니다.

**주의:** 진행 기록은 기본적으로 사용 중인 브라우저의 로컬 저장소에 보관됩니다. 다른 휴대폰이나 브라우저로 자동 동기화되지 않으며, 개인정보 보호 모드나 브라우저 데이터 삭제 시 기록이 지워질 수 있습니다. 다른 기기로 옮기기 전에 JSON 백업 파일을 저장해 주세요.

## 스마트폰에서 즐기기

- Chrome, Safari 등 모바일 브라우저에서 **같은 웹사이트 URL**로 접속합니다.
- 별도 앱 설치 없이 터치로 조작할 수 있도록 반응형 화면과 게임별 조작 버튼을 제공합니다.
- 지뢰찾기의 깃발 모드, 시카쿠·블록 퍼즐의 터치/드래그, 게임판 확대 후 좌우 이동 버튼을 활용할 수 있습니다.
- 화면 오른쪽 아래의 **🔠 글씨·화면** 버튼을 누르면 게임을 보면서 글씨 크기(25~200%)와 전체 화면 배율(70~130%)을 바로 조절할 수 있습니다. PC에서는 화면 상단에도 버튼이 있습니다.
- 글씨를 너무 작게 설정해도 빠른 조절창은 읽을 수 있는 크기로 유지됩니다. 퍼즐 숫자·타일 등은 게임판의 자체 크기 조절 기능을 사용합니다.
- 글씨·화면 크기는 독립된 **🔠 글씨·화면** 빠른 조절창에서만 설정할 수 있습니다. ⚙ 설정창에는 중복 조절 항목이 없습니다.
- **⚙ 설정 → 배경음악과 효과음 → 선택된 곡**을 누르면 별도 음악 선택창이 열립니다. 곡 이름과 현재 선택 상태를 확인하고 원하는 곡을 터치하면 바로 선택되며 창은 자동으로 닫힙니다.

## 개발자용 · 로컬 실행 및 배포

`index.html`을 직접 열거나 정적 웹 서버로 폴더를 실행할 수 있습니다. GitHub Pages에 게시하려면:

1. GitHub에서 **Public** 저장소를 만듭니다.
2. `index.html`이 저장소 **최상위(root)** 에 보이도록 이 폴더의 내용물을 업로드합니다. **ZIP 파일 자체는 업로드하지 않습니다.**
3. 저장소의 **설정(Settings) → Pages → Source: Deploy from a branch → main / (root) → 저장(Save)** 순서로 설정합니다.
4. 배포가 완료되면 `https://사용자이름.github.io/저장소이름/` 형태의 URL로 접속합니다.
5. PC 및 실제 스마트폰에서 게임 6종, 도움말, 저장·새로고침, 음악을 확인합니다.

**기술:** HTML5, CSS3, JavaScript / GitHub Pages(정적 호스팅). 게임 플레이용 서버나 별도의 계정 가입은 필요하지 않습니다.

**버전:** v52 — 새 버전 안내, 게임판 화면 맞춤 기본값, 크기 조절 버튼 상시 표시, 상태 안내 좌우 흔들림 방지.

## v51 모바일 드래그 개선

- 시카쿠와 블록 퍼즐의 상태 안내 영역 높이를 고정하여 드래그 도중 줄바꿈이 생겨도 게임판이 밀리지 않게 개선했습니다.
- 블록을 손가락으로 끌면 모양이 보드의 격자에 딱 맞춰 이동하고, 초록색으로 배치 가능 여부를 확인할 수 있습니다. 모바일에서는 블록을 손가락보다 위에 보여 가림을 줄였습니다.
- 초록색으로 표시된 위치에서 손을 떼면 배치됩니다. 빨간색으로 표시되면 놓을 수 없는 위치입니다. 기존 블록 선택 후 게임판 터치 방식도 지원합니다.
- 게시 후 갱신되지 않은 화면이 보이지 않도록 CSS와 JavaScript 요청에 `v=51` 버전 값을 넣었습니다.

## 업데이트 안내

- 배포된 새 버전이 발견되면 상단에 **새 버전이 준비됐어요** 알림이 표시됩니다. **최신 버전 열기**를 눌러야 새로고침됩니다. 게임 플레이 도중 자동으로 종료하거나 재시작하지 않습니다.
- 업데이트 버튼은 기존 브라우저의 기록과 설정을 삭제하지 않습니다. 단, 저장이 차단되어 있거나 배포 직전인 경우를 대비해 중요한 기록은 JSON 백업을 권장합니다.
- 최신 버전으로 배포할 때에는 `index.html`의 버전 및 CSS·JS `?v=번호`, `version.json`의 `version`, `script.js`에 포함된 `VERSION` 상수를 **동일한 버전 번호**로 올려야 합니다. 그렇지 않으면 알림이 동작하지 않을 수 있습니다.
- GitHub Pages는 커밋과 공개 사이트 반영 사이에 지연이나 브라우저 캐시가 있을 수 있습니다. 알림은 완전한 실시간 반영을 보장하지 않습니다.
- v51 및 이전에 열린 페이지에는 자동 업데이트 감지 코드가 없으므로 최초 한 번 v52로 이동하거나 브라우저를 새로고침해야 합니다.

## v52 조작 개선

- 화면 오른쪽 아래 버전 표시는 실제 실행 중인 버전과 같게 표시합니다.
- 시카쿠와 블록 퍼즐의 성공·실패 안내 색상과 문구가 바뀌어도 안내 상자의 가로 폭이 흔들리지 않도록 수정했습니다.
- 게임별 확대·축소 조작은 별도 펼치기 없이 항상 보입니다.
- PC와 모바일에서 게임을 처음 열 때 **화면 맞춤**을 적용합니다. 사용자가 수동 저장한 게임별 배율이 있으면 그 설정을 우선합니다. 옵션을 꺼 둔 사용자는 설정에서 다시 켤 수 있습니다.

## 최신 화면으로 접속하기

- 저장소의 **지금 플레이하기** 링크는 `play.html`을 거쳐 게임을 엽니다. 매번 새로운 확인 값을 사용해 이전 HTML 캐시를 우회합니다.
- GitHub 저장소의 About → Website에도 위 `play.html` 주소를 한 번 등록하면 앞으로 버전이 바뀌더라도 링크를 바꿀 필요가 없습니다.
- 실제 새 버전은 **GitHub Pages 배포가 완료된 다음** 표시됩니다. 배포 중에는 이전 버전이 잠시 보일 수 있습니다.
- 게임 데이터는 같은 도메인과 경로를 사용하므로 기록·레벨·설정 등을 삭제하지 않습니다. 브라우저 저장소를 직접 초기화하지 마세요.
