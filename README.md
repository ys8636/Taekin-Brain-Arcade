# 🎮 TAEKIN BRAIN ARCADE

**TAEKIN BRAIN ARCADE**는 숫자야구, 2048, 지뢰찾기, 파이프 연결, 시카쿠, 블록 퍼즐을 한곳에서 즐길 수 있는 무료 두뇌 게임 사이트입니다. 별도의 설치나 회원가입 없이 PC와 스마트폰 브라우저에서 플레이할 수 있습니다.

### [▶ 지금 게임 시작하기](https://ys8636.github.io/Taekin-Brain-Arcade/play.html)

## 처음 시작하는 방법

1. 위의 **게임 시작하기** 링크를 엽니다.
2. 상단의 **게임** 메뉴에서 원하는 게임을 선택합니다.
3. **난이도**를 고르고 **1단계**부터 시작합니다. 단계를 클리어하면 다음 단계가 열립니다.
4. 게임의 규칙을 모르겠다면 게임 제목 옆 **📖 도움말**을 눌러 보세요.
5. 게임을 플레이하며 단계와 목표를 달성하고, **내 기록** 메뉴에서 성과를 확인해 보세요.

## 🕹️ 게임 6종 즐기는 방법

### ⚾ 숫자야구 — 숨겨진 숫자 추리하기

서로 다른 숫자로 만들어진 비밀 번호를 맞히는 게임입니다. 화면에 표시된 자릿수에 맞춰 숫자를 입력하고 결과를 확인하세요.

- **스트라이크(S)**: 숫자와 자리가 모두 맞습니다.
- **볼(B)**: 숫자는 포함되어 있지만 자리가 다릅니다.
- **아웃**: 입력한 숫자가 정답에 하나도 없습니다.

결과를 비교해 후보를 줄여 나가세요. 단계에 따라 자릿수와 시도 횟수 등의 조건이 달라집니다.

### 🔢 2048 — 같은 숫자를 합치기

상하좌우로 타일을 움직여 **같은 숫자의 타일 두 개를 하나로 합치는 게임**입니다. 예를 들어 `2 + 2 → 4`, `4 + 4 → 8`이 됩니다.

- **PC**: 키보드 방향키 또는 화면의 방향 버튼으로 이동합니다.
- **스마트폰**: 게임판을 위·아래·왼쪽·오른쪽으로 밀거나 방향 버튼을 누릅니다.
- 단계에 표시된 **목표 타일과 점수**를 달성하세요. 필요하면 되돌리기 기능도 이용할 수 있습니다.

### 💣 지뢰찾기 — 지뢰를 피해 안전한 칸 열기

숨겨진 지뢰를 피해서 **지뢰가 없는 칸을 모두 여는 게임**입니다.

- 칸을 누르면 숫자가 표시되거나 주변 칸이 열립니다. **숫자는 주변 8칸에 숨어 있는 지뢰의 개수**를 뜻합니다.
- 지뢰가 있을 것 같은 칸은 **깃발 모드**로 표시하세요.
- 모든 안전한 칸을 열면 성공입니다. 지뢰가 있는 칸을 열면 실패합니다.
- 처음 여는 칸은 안전하게 시작할 수 있도록 설계되어 있습니다.

### 🔧 파이프 연결 — 물길 완성하기

파이프를 회전시켜 **시작점에서 도착점까지 이어지는 길**을 완성하는 게임입니다.

- 파이프 칸을 누르거나 터치하면 방향이 회전합니다.
- 파이프의 열린 부분끼리 연결되도록 맞추세요.
- 연결 상태와 물 흐름을 보면서 막힌 구간을 찾아 수정해 보세요.

### 🧩 시카쿠 — 숫자에 맞는 직사각형 만들기

게임판을 서로 겹치지 않는 직사각형으로 나누는 퍼즐입니다.

- 각 직사각형에는 **숫자가 정확히 하나** 들어가야 합니다.
- 직사각형의 **칸 개수(넓이)는 그 안의 숫자와 같아야** 합니다. 예를 들어 `6`이 있는 영역은 `2×3` 또는 `1×6`처럼 여섯 칸으로 만듭니다.
- 두 모서리 칸을 선택하거나 스마트폰에서 드래그해 영역을 지정합니다.
- 모든 칸을 빈틈이나 겹침 없이 채우면 성공입니다.

### 🟩 블록 퍼즐 — 블록을 놓아 줄 지우기

여러 모양의 블록을 빈칸에 배치하고 **가로줄이나 세로줄을 완성해 없애는 게임**입니다.

- 아래의 블록을 골라 게임판에 놓거나, 블록을 손가락으로 끌어서 배치합니다.
- 배치 미리보기가 **초록색**이면 놓을 수 있고, **빨간색**이면 놓을 수 없습니다.
- 스마트폰에서는 블록 그림이 손가락보다 약간 위에 나타나며 게임판 칸에 맞춰 움직입니다.
- 줄을 지워 점수를 쌓고 단계별 목표 점수에 도전하세요.

## ✨ 단계와 즐길 거리

- **5가지 난이도**: 쉬움 · 보통 · 어려움 · 매우 어려움 · 전문가
- **게임당 250단계**, 전체 **1,500단계**: 각 난이도에 50단계가 있습니다.
- **보스 단계**: 각 난이도의 10·20·30·40·50단계는 특별한 도전 구간입니다.
- **도움말과 힌트**: 규칙과 조작법을 확인하고, 막히는 문제에서 힌트를 사용할 수 있습니다. 일부 게임에서는 힌트 사용이 별점에 영향을 줄 수 있습니다.
- **도전·보상**: 종합 도전, 일일·주간 미션, 레벨과 칭호, 배지·트로피, 프로필과 사이트 꾸미기를 즐길 수 있습니다.

## 📱 스마트폰에서 편하게 플레이하기

- 별도 앱 없이 Chrome·Safari 등 모바일 브라우저에서 위 링크를 열면 됩니다.
- 게임판 주변의 **− / ＋ / 기본 / 화면 맞춤** 버튼으로 게임판 크기를 조절할 수 있습니다. 처음에는 화면에 맞는 크기로 표시됩니다.
- 화면의 **🔠 글씨·화면** 버튼에서 글씨 크기(25~200%)와 전체 화면 크기(70~130%)를 조절할 수 있습니다.
- 시카쿠와 블록 퍼즐은 **드래그 또는 칸 선택** 방식으로 조작할 수 있고, 2048은 화면 스와이프를 지원합니다.
- 음악을 바꾸려면 **⚙ 설정 → 음악 선택**을 눌러 원하는 곡을 선택하세요. 음악 및 효과음의 크기도 조절할 수 있습니다.

## 💾 플레이 기록 저장하기

게임 진행 기록과 설정은 **현재 사용 중인 기기의 브라우저**에 저장됩니다. 같은 기기에서 다시 방문하면 진행 상황을 이어갈 수 있습니다.

**다른 스마트폰이나 PC로 기록을 옮기려면 JSON 백업·복원 기능을 사용하세요.** 브라우저 데이터를 삭제하거나 시크릿 모드로 플레이하면 저장된 기록이 유지되지 않을 수 있습니다.

즐거운 플레이 되세요! 🎮
